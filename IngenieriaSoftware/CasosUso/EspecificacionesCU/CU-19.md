### Caso de Uso 19 (CU-19)
* **Nombre:** Consultar Prestigio
* **Descripción:** el gestor consulta el nivel de prestigio actual e histórico del zoológico y los indicadores que influyen en el prestigio actual.
* **Actores:** Gestor del Zoo
* **Precondición:** existe una partida seleccionada y se pueden recuperar los valores de prestigio persistidos y sus estadísticas globales.
* **Postcondición:** el sistema presenta el prestigio actual, el máximo histórico y las estadísticas relacionadas, sin modificar la partida ni recalcular niveles durante la consulta.
* **Situaciones de Error:** no se puede recuperar el prestigio actual, el máximo histórico o las estadísticas globales necesarias para presentarlos.
* **Situación del Sistema en caso de Error:** el sistema comunica qué dato no está disponible y no sustituye el nivel por un valor supuesto. La consulta no recalcula prestigio, progreso de misiones ni métricas.
* **Flujo Básico:**
  1. El gestor abre el indicador de prestigio de la pantalla inicial o la opción de consultar prestigio.
  2. El sistema recupera el nivel actual persistido y el máximo histórico alcanzado.
  3. El sistema presenta ambos valores junto con las estadísticas globales que influyen en el nivel actual: cantidad de animales vivos alojados y satisfacción global disponible.
  4. El sistema muestra los datos con etiquetas descriptivas y sin exponer identificadores o claves internas.
  5. El gestor consulta el panel. La navegación o actualización de la vista no dispara la evaluación de umbrales ni produce cambios de prestigio.
* **Flujo alternativo:**
  * **1.a: no hay una partida seleccionada.** El sistema informa de que no existen datos de prestigio disponibles.
  * **2.a: no se puede recuperar el nivel actual o el máximo histórico.** El sistema indica el valor no disponible y no lo sustituye por cero ni por el otro valor.
  * **3.a: no hay métrica global de satisfacción disponible.** El sistema muestra la satisfacción como no disponible y no calcula una nueva al abrir el panel.
  * **3.b: no se puede determinar la cantidad vigente de animales vivos alojados.** El sistema identifica la estadística no disponible y no deduce el prestigio a partir de datos parciales.
  * **4.a: se detecta una referencia técnica en los datos.** El sistema la omite de la interfaz y conserva las etiquetas legibles.
  * **5.a: el gestor vuelve a abrir el panel tras una mutación o ciclo confirmado.** El sistema consulta el nuevo resultado persistido; el recálculo corresponde al evento que confirmó la mutación o el ciclo, no a la lectura.

### Puntos pendientes
Los umbrales concretos de animales y satisfacción por nivel, así como el comportamiento inicial o cuando no hay animales computables, están pendientes de parametrización. El nivel actual se evalúa conforme a los umbrales configurados y el máximo histórico no disminuye.
