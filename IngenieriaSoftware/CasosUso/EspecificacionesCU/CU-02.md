### Caso de Uso 2 (CU-02)
* **Nombre:** Configurar Espacio
* **Descripción:** el gestor modifica la denominación y/o el hábitat asignado de un espacio existente.
* **Actores:** Gestor del Zoo
* **Precondición:** existe el espacio que se desea configurar.
* **Postcondición:** se actualiza la denominación y/o el hábitat asignado; la capacidad máxima del espacio permanece inalterada. Si cambia el hábitat, el de destino dispone de capacidad suficiente.
* **Flujo Básico:**
  1. El gestor selecciona un espacio existente.
  2. Indica una nueva denominación y/o selecciona el hábitat de destino.
  3. Si se cambia el hábitat, el sistema valida que el destino dispone de capacidad suficiente.
  4. El sistema aplica la configuración solicitada sin modificar la capacidad máxima del espacio.
* **Flujo alternativo:**
  * **3.a: el hábitat de destino no dispone de capacidad suficiente.** El sistema no aplica el cambio de hábitat.
  * **3.b: el espacio ya tiene esa denominación en el hábitat de destino.** El sistema rechaza la configuración y conserva los valores anteriores.
  * **3.c: el hábitat de destino es inválido o está bloqueado.** No se aplica el cambio y se conserva la configuración anterior.
  * **3.d: se solicitan a la vez un cambio de denominación y de hábitat, pero falla alguna validación.** El sistema no aplica parcialmente la configuración y conserva los valores anteriores.
